# Web Enterprise Community Responsive Theme

A professionally built backend theme that brings a modern, responsive,
Enterprise-grade interface to Odoo Community — without any Enterprise
dependency or upsell dialog.

## Why this exists

Odoo Enterprise ships a polished backend UI — app switcher, dark mode,
responsive navigation — that Community users don't get out of the box.
This theme delivers that experience built from scratch against Odoo's own
public `web` addon APIs, with original code, styling and branding.

## Features

- **Full-screen app switcher** — a six-per-row Enterprise-style grid with
  instant search and drag-to-reorder (order is remembered per browser).
- **Redesigned navigation bar** — gets out of the way entirely on the home
  screen, and turns into a back control on hover while inside an app.
- **Complete dark mode** — every core widget, not just the navbar and app
  switcher. The dark palette is injected ahead of Odoo's own variables, so
  even addons that ship no dark-mode assets of their own (`account`,
  `sale`, `stock` — none of which do) render correctly.
- **Optional compact list density**, toggled per user and remembered.
- **Refined kanban cards**, a mobile-usable pivot table and a polished
  mobile burger menu.
- **Flat, rounded Bootstrap component set** and a branded login screen that
  follows the light/dark preference.
- **RTL-ready** and translated into **54 languages**, Arabic included.

## Installation

1. Copy `web_enterprise_community_responsive_theme` into your Odoo addons
   path.
2. Restart the Odoo server.
3. Update the Apps list, then search for the theme and install it.

Dark mode is toggled per user from the user menu (top right).

## Compatibility

- Odoo **18.0** Community.
- No dependency beyond Odoo's own `web` module.
